# 将棋CPUの思考エンジンと学習

`shogi.html` のCPUの中身です。

- `engine.js` … 思考エンジン。指し手生成・反復深化アルファベータ探索（静止探索・置換表・LMR）・評価関数。
- `train.js` … 評価関数の学習。自己対局 → 学習 → 前の重みと対局して強さを測る、を繰り返す。
- `weights.txt` … 学習済みの重み（Int16 を base64 にしたもの）。
- `build.js` … `engine.js` と `weights.txt` を `shogi.html` の `<script id="engine">` に書き込む。
- `bench.js` … AIの評価。テスト局面での正解一致率・悪手率・詰みの発見と、エンジン同士の対局。
- `bench-positions.json` … テスト局面339個（自己対局から取り、4秒読んだ手を「正解」としたもの）。

## 評価関数

約1万個の重みの線形和です。

- 駒の種類 × 盤上の位置
- 駒の種類 × 自玉との相対位置、駒の種類 × 敵玉との相対位置（玉の守り・攻めを表す）
- 持ち駒の種類 × 枚数

最初は駒の価値だけを入れておき、自己対局で学習します。
目標は「探索で出た評価値」と「その対局の勝敗」を半分ずつ混ぜた勝率で、評価値を勝率に変換したもの（sigmoid(評価値/600)）がそれに近づくよう、Adam でロジスティック回帰します。

## 学習の結果

自己対局1000局ずつで6ラウンド学習しました。1手8000局面読みで、前のラウンドの重みと200局ずつ対局した結果です。

| ラウンド | 前のラウンドに対する勝率 |
| --- | --- |
| 1 | 60.8%（駒の価値だけの重みに対して） |
| 2 | 57.0% |
| 3 | 53.5% |
| 4 | 49.3% |
| 5 | 50.0% |
| 6 | 46.5% |

4ラウンド目からは伸びなくなりました。そこで、一番成績のよかった3ラウンド目の重みを使っています。
この重みは、駒の価値だけの評価に対して400局で244勝152敗4分（勝率61.5%、Elo差 +81）でした。
線形の評価関数なので、データを増やしてもこのあたりが限界のようです。

## 探索の改善と評価（2回目）

探索に次の改善を入れました。

- 静止探索で王手されているときは、全部の応手を読む（以前は王手を放置した評価で打ち切っていた）
- null move pruning と futility pruning で、無駄な読みを減らす（同じ3秒で深さ11→19）
- 千日手（読み筋や対局中に出た局面の繰り返し）を引き分けとして扱う
- 時間切れのとき、深さの違う評価値どうしを比べていたバグを直した
- 指せる手が1つしかないとき、評価値を0にしていたのをやめ、少し読んで正しい評価値を出す

改善前のエンジンとの対局（同じ序盤を先後入れ替え）：

| 1手の時間 | 結果 | 勝率 | Elo差 |
| --- | --- | --- | --- |
| 0.1秒 | 110勝 80敗 10分 | 57.5% | +53 |
| 0.5秒 | 65勝 36敗 3分 | 63.9% | +100 |

試したけれど入れなかった案：王手延長をすべての深さに広げる（勝率42.0%）、LMRを強める（勝率48.8%）。

改善後の各レベルの成績（`node shogi-ai/bench.js levels`）：

| レベル | 正解一致 | 平均損失 | 悪手（損失300以上） | 大悪手（1000以上） | 詰み発見 |
| --- | --- | --- | --- | --- | --- |
| 入門 | 22.1% | 299 | 31.9% | 8.3% | 7/10 |
| 初級 | 33.3% | 204 | 19.8% | 4.4% | 6/10 |
| 中級 | 46.3% | 96 | 10.3% | 0.9% | 9/10 |
| 上級 | 81.7% | 17 | 1.5% | 0.3% | 10/10 |
| 有段 | 79.6% | 20 | 1.5% | 0.9% | 10/10 |

「正解」は改善前のエンジンが4秒読んだ手です。正解自体が完璧ではないため、上級・有段の一致率は強さの目安にしかなりません（改善前のエンジン自身は有段で97%一致しますが、対局では改善後の方が強い）。強さの比較には対局の結果を使ってください。

```sh
node shogi-ai/bench.js levels                                   # 各レベルの成績
node shogi-ai/bench.js match shogi-ai/engine.js 旧engine.js 100 100  # 対局で比較（100序盤×先後、1手0.1秒）
```

## 学習し直すとき

```sh
node shogi-ai/train.js 4 1000   # 4ラウンド、1ラウンド1000局（4コアで1時間半ほど）
node shogi-ai/build.js          # shogi.html に反映
```

`weights.txt` があれば、その続きから学習します。
